# faceblur file-I/O write sites, format 1
#
# Every reviewed file-I/O line of scripts/sast/allowlist.txt, classified by what it can do to the file system. The
# library writes nothing to disk except the masked output: a write kind is allowed only for the finished, checked
# masked JPEG (masked-output), the owner-only temporary file next to the target that holds only that output
# (temp-file), and the removal of the call's own temporary or fallback file (cleanup). scripts/check-write-sites.py
# fails when an allow-list entry has no row here (a new file-I/O line must be classified), when a row has no allow-list
# entry, when a line that can write is classified as a kind that does not write, when a write kind appears outside the
# file-mode writer files, when a read-open row does not name an existing test that proves its read-only flags, or when
# a classified line names an app storage or temporary directory (the script's rules 7 and 8 also scan the sources).
# Each row needs the same security review as its allow-list entry.
#
# Kinds that do not write: read, read-open (an open whose flags come from its callers; the named test proves they are
# read-only), stat, descriptor, path-name (lexical path handling only), memory (anonymous memory, no file).
# Kinds that write: masked-output, temp-file, cleanup.
#
# Format: the first two lines above stay exactly as they are; then comment lines (#) and one row per line, five
# fields separated by a TAB:   <rule id>  <path>  <SHA-256 of the trimmed line>  <kind>  <note>
